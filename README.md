# Calgary 311: Turning Requests into Insights 📊

A Business Intelligence capstone project exploring Calgary 311 waste service requests to identify trends and opportunities to improve service efficiency.

## Project Members

- Asma A.
- Chelsea D.
- Marian O.
- Marjorie T.
- Steffi N.

## Project Goals

- Analyze patterns in waste related service requests.
- Measure how long requests take to resolve.
- Identify opportunities to improve service delivery.
- Turn findings into clear, actionable insights.

## KPIs

- **Average Resolution Time:** How long it takes to resolve a service request.
- **Cost per Request:** The average cost of handling a request, subject to available cost data.

## Planned Tools

- **SQL** for data preparation and analysis.
- **Power BI** for dashboards and visualisations.

## Project Scope

KPI development, process mapping, data architecture planning, and analysis of Calgary 311 waste service requests.

## Status

- In progress: analysis, dashboards, and findings will be added as the project develops.
